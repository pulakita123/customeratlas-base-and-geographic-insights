# Project Overview
This project focuses on analyzing customer data to understand customer distribution, tenure patterns, and growth trends. Using Excel, I transformed raw customer data into meaningful insights through data cleaning, pivot-based analysis, and an interactive dashboard.
The goal of this project is to demonstrate core data analyst skills including data preparation, KPI definition, and business-focused reporting.

# Business Questions Addressed
How many active customers are in the dataset?
How has customer acquisition changed over time?
What is the average customer tenure?
Which countries and companies contribute the most customers?
Is the customer base concentrated or diversified?

# Tools & Techniques Used
Microsoft Excel
Data cleaning and transformation
PivotTables for aggregation
Slicers for interactivity
Conditional formatting for visual emphasis
Dashboard design best practices

# Data Preparation
Removed duplicates and invalid records
Standardized country and company names
Created derived fields such as subscription year and tenure buckets
Validated counts after cleaning to ensure data consistency

# Key Metrics (KPIs)

Total Customers
New Customers by Year
Average Customer Tenure
Customer Distribution by Country
Customer Distribution by Company

# Dashboard Features
Interactive filters (Year, Country, Company)
KPI cards for quick insights
Tables highlighting top countries and companies
Distribution visuals supporting tenure and geography analysis

# Key Takeaways
The customer base shows clear geographic and company-level concentration
A significant portion of customers have long-term tenure, indicating stability
Customer acquisition trends vary by subscription year

# About This Project
This project was created as part of my learning journey toward becoming an entry-level data analyst. It demonstrates my ability to clean data, derive insights, and communicate findings through dashboards.
